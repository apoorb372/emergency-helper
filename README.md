# 🚨 AI Emergency Helper

AI Emergency Helper is a smart web-based application designed to assist users during emergency situations.

## 🔥 Features
- 🚨 Emergency alert system
- 🧠 AI-based response guidance
- 🎤 Voice assistant support
- ⏱️ Auto alert if no response
- 📍 Future scope: location sharing & smart calling

## 💡 Purpose
This project aims to provide quick and intelligent help during critical situations and improve safety using technology.
